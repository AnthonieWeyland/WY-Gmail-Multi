# WY Gmail Multi: Privacy Policy

Last updated: October 24, 2026

WY Gmail Multi ("the application") is a personal tool written and used by a single individual to work with their own Gmail accounts from their own computer. It is not distributed, sold or offered to anyone else. This policy explains how the application handles data, in plain language.

## What data the application accesses

With the user's explicit permission, granted through Google's standard sign-in screen, the application uses the Gmail API to read messages, search mail, change labels, create drafts, and (only when the user turns that option on) send a draft the user has approved. The permission requested is the Gmail "modify" scope.

## Where data is stored

Sign-in credentials (OAuth refresh tokens) are stored only on the user's own computer, in a folder that only the user's operating-system account can open. Email content is read on demand and shown to the user on that same computer; attachments or message copies the user chooses to save are written to a folder on that computer. Nothing is stored on any server operated by the application's author.

## Who data is shared with

Data is exchanged only between the user's computer and Google's Gmail API. The application does not send mail content, contacts, or credentials to any third party, analytics service, or other server. The application's author does not receive, collect, or see any data from any account other than their own.

## Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Data obtained through Gmail is used only to provide the application's features to the user who granted access, is not used for advertising, and is not sold or transferred to others.

## How to revoke access

The user can remove the application's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions), or by running the application's own remove command, which revokes the token at Google and deletes it from the computer.

## Changes and contact

If this policy changes, the updated version will be published on this page. Questions can be sent to the developer contact address listed on the application's Google sign-in screen.
