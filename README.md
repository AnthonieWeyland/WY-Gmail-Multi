# WY Gmail Multi

WY Gmail Multi is a small, private tool that lets one person work with several of their own Gmail accounts from a helper program running on their own computer. It is a single script that runs locally, talks only to Google's own Gmail API, and is used by its author alone.

This page exists because Google requires every OAuth application in production to list a public home page and a privacy policy, even when the application is a personal tool with a single user.

- Privacy policy: [PRIVACY.md](PRIVACY.md)
- Terms of service: [TERMS.md](TERMS.md)

## What it does

- Searches, reads and labels mail across the connected accounts.
- Saves drafts, which the user then reviews and sends from Gmail itself.
- Saves attachments and original message copies to a folder on the user's own computer.

## What it does not do

- It is not offered to the public and has no users other than its author.
- It does not store, transmit or share mail with anyone other than Google and the user.
- It cannot delete or trash mail, create filters or forwarding rules, or change Gmail settings.
